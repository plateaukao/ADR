# Blog: August 2026 GitHub activity report (zh-TW)

Added the third monthly/period GitHub activity report to the blog:
`content/posts/github-activity-august-2026/index.html`, following the format of the
April–May and June–July reports (same TOML front matter, `layout = "report"`, same
dark single-file HTML with stat cards, weekly/daily bar charts, hero project cards,
per-repo table and narrative analysis). Unlike the earlier two, this one is written
in **zh-TW** — an English version was generated first, then dropped at review; only
the Chinese version ships, under the clean slug `github-activity-august-2026`.

## How the data was gathered

All numbers come from local git history, not the GitHub API: every repo under
`~/src` was scanned for commits authored by `daniel.kao@gmail.com` in August 2026,
with `--numstat` output classified per file extension into code / assets & data /
docs. Two pitfalls surfaced and were fixed during collection:

- `git log --all` includes `refs/stash` — stash entries ("On master: …",
  "index on master: …") inflated several repos' counts (and made a `sharik` repo
  appear active with 2 phantom commits). Collection switched to
  `--branches --remotes --tags`, dropping 4 phantom commits (579 → 575).
- The report HTML itself is generated by a Python script (numbers, bar heights and
  percentages all computed, never hand-typed), with tag-balance validation and a
  totals cross-check (heroes + table rows must equal the grand total) before saving.

## What's excluded, and why

Three repos are excluded from every number, stated in the report header:

- **ADR** (326 commits) — auto-generated after each Claude Code commit.
- **blog** (13 commits) — content, not engineering.
- **rocket** (106 commits) — the TASTI 2026 rocket-GNC competition workspace.
  Initially included as the #3 hero with an asterisk (its experiment harness
  snapshots full simulator state to JSON — +4,850,904 generated lines that drown
  every chart), but on review excluded entirely: it is a lab notebook, not
  open-source development. Its 106 commits, 4.85M telemetry lines and the
  climb from 5 to 8 balloon pops survive only as a one-line exclusion note and a
  short analysis paragraph.
